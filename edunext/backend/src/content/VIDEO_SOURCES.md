# Lesson video sources

Each seeded lesson has a **visual** (explainer/overview) and a **practical**
(hands-on/code-along) YouTube video. All IDs below were **verified via YouTube
oEmbed** (the video exists and allows embedding) at sourcing time — none are
invented. Editable in `backend/src/content/videos.js`.

**Licence note (honest):** these are standard YouTube videos whose **embedding is
enabled** (confirmed by oEmbed). That satisfies "channels that allow embedding",
but most are *not* Creative Commons — so this is embed-permitted reuse, not a CC
licence. For a production product, prefer explicitly CC-licensed or
institution-owned sources (NPTEL, MIT OCW). A video can also be removed or have
embedding disabled later; the player handles that with a fallback.
